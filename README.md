# 「五心」苏式工匠 · 校园数字形象模板库

江苏联合职业技术学院张家港分院 信息工程系 · 2022 级高职五年级毕业设计教学参考。

在线地址：<https://gxglad.github.io/wuxin/>

## 这是什么

一份可以直接打开、直接照着做的毕业设计模板库。按三个专业分成七套模板，每套对应《2022 级毕业设计方案》表 2 中的一个可用选题，页面里包含：

- 作品主体（能点、能切、能演示的网页 Demo）
- 设计说明（选题背景、设计思路、「五心」主题体现、技术实现、可拓展方向）

学生不是抄页面，而是看一套完整的作品应该长什么样、要说明哪些事。

assets/css/template.css  模板页样式

## 本地打开

直接双击 `index.html` 即可，无需服务器、无需构建、无任何外部依赖（不联网也能看）。

## 改一套模板给自己的题目用

1. 复制一份 `app/t1.html` 之类的文件，改文件名；
2. 改 `<main>` 里的 `h1`、`.lede`、`.tag` 和 `spec` 五节文字；
3. Demo 部分的结构和交互可以整段替换，配色改 `.d-*` 里的 CSS 变量即可；
4. 首页 `index.html` 里对应的链接与文案同步改掉。

## 发布

纯静态站点，推送到 GitHub 后在仓库 Settings → Pages 选择 `main` 分支根目录即可。
