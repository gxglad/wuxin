01选题背景

云计算的作业最容易被做成“三张架构图加一段配置代码”。评审看不懂，学生自己也讲不清。这个题目换了个做法：把一台虚拟机从开机到停机、从占用到计费的全过程放到网页上，让不会用命令行的人也能看懂“云”到底在管什么。

02设计思路

按真实控制台的信息层级来做，但砍掉 80% 的菜单。只留四个问题：开了几台、跑得怎么样、占了多少、要花多少钱。

  • 指标一律从实例数组现算，不做硬编码，改一台就全身联动。
  • 启停不弹窗、不跳页，就地改状态，一秒内看到结果。
  • 配色克制：只有“运行绿、告警红、存储四色”三组颜色。
  • 手机上表格收起次要列，保留实例名、状态和操作。

03「五心」主题体现

红心：演示数据全部用学校真实场景命名——作品素材、课程录像、虚拟机镜像。仁心：每个指标后都有一句人话解释，不假设读者懂 vCPU 与 IOPS。恒心：六个实例的 CPU 曲线一条条调过，让白天的峰值和夜间的空档对得上。匠心：表格列宽、数字右对齐、状态点直径全部对齐 4 像素栅格。创心：纯 SVG 画曲线，不引任何图表库，单文件在答辩机房里也能直接打开。

04技术实现

状态存一个数组，每次操作只改一个字段，然后统一走一次 render()：表格、KPI、曲线、费用全部重算。曲线用折线点坐标拼 polyline，面积用同一条线闭合填充。

状态机（run / stop） 派生指标计算 SVG polyline 折线 range 滑块联动 CSS Grid 控制台布局 表格响应式收列

05可拓展方向

  • 接真实 OpenStack 或云厂商 API，把演示数据换成实时数据。
  • 加登录与角色（学生只能启停自己的机器）。
  • 导出月度账单为 CSV，交给学校财务走报销流程。
