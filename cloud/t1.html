01选题背景

系里每年的毕业作品都散落在 U 盘、微信群和几台公用电脑里。新生想看看上一届做了什么，得靠人转链接；企业来招人，看到的往往只是几张压缩过的图片。这个题目的真实价值不在于把作品摆得好看，而在于让“作品”变成一条有字段、能检索、能引用的记录。

02设计思路

整站只有一个动作被反复强化：找东西然后点开。所以首页不做轮播、不做大 banner，直接给筛选条和墙。

  • 封面不追求统一，颜色由学生自选，平台只负责排版秩序。
  • 元数据固定六个字段：专业、年份、载体、技术、作者、一句话说明。
  • 灯箱里可以直接翻上一件、下一件，不用退出重进。
  • 收藏写在本地，答辩演示时不必登录也能演。

03「五心」主题体现

红心：首屏写清楚“这些作品是给谁看的”，把学校对外的形象放在功能之上。仁心：每件作品配一句人话说明，不默认读者懂专业术语。恒心：一百多件作品的字段被逐条校对过，宁可少收一件，不放进错的信息。匠心：卡片留白、行高、编号栏的基线全部对齐同一套栅格。创心：纯 CSS 生成封面底纹，零图片依赖，一百件作品也不会拖慢打开速度。

04技术实现

作品数据是一个对象数组，渲染、筛选、排序、灯箱都跑在同一份数据上；封面用 CSS 变量控制颜色和斜纹纹理，不加载任何图片。搜索对名称、作者、标签做包含匹配，输入即过滤。

05可拓展方向

  • 接真实的静态 JSON 或学校现有资源库接口，替换演示数据。
  • 加学生登录与作品提交表单，后台走审核流。
  • 按班级、按教师生成作品集页面，用于家长会和招生宣讲。
