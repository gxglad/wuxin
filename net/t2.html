01选题背景

招生季最常见的场景是：家长在手机上搜学校，看到的要么是几张全景照片，要么是一段两分钟的航拍视频。前者看不出空间关系，后者只能被动观看。本选题把校园拆成六个可停留的点位，用"场景 + 热点 + 说明"的方式让人自己决定看哪里、看多久。

02设计思路

不追求 3D 还原，而是做"氛围级"的矢量场景：用色块、剪影和光点表达空间，重点放在信息层——每个点位都有名称、开放时间、步行距离与一句具体 description。

  • 场景切换用横向位移，保持"走在路上"的空间连续感。
  • 热点只放三个以内的关键信息，不做百科全书。
  • 右侧信息面板随场景更新，文字比图片承担更多解释。
  • 地图与场景双向联动，点击任一处都能跳转。

03「五心」主题体现

红心：南校门与展厅两个点位承担对外表达，把学校的历史与成果放在参观动线的首尾。仁心：每个点位都写了"人"的细节——自行车铃、食堂蒸汽、夜跑的灯，而不是坪数与面积。恒心：六个场景的透视消失点统一在同一条水平线上，改到第四版才对齐。匠心：热点呼吸动画统一 2.6 秒周期，与场景切换时长形成节奏差。创心：全部场景用 SVG 手绘，单文件即可运行，不依赖任何 3D 引擎。

04技术实现

场景容器宽度 200%，通过 translateX 位移切换；指针事件计算位移量，超过阈值即翻页；自动巡游用 setInterval 驱动，交互后自动暂停。

translateX 场景位移 Pointer Events 拖拽 SVG 矢量场景 requestAnimation 节流 数据驱动信息面板 移动端手势适配

05可拓展方向

  • 替换为真实全景照片，用 CSS 3D 或 WebGL 做球面投影。
  • 增加语音讲解与字幕，服务不便阅读的访客。
  • 接入二维码，扫码即可从校园实地的展牌进入对应点位。
