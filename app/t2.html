01选题背景

学校门户是家长、考生、在校生和企业第一次“认识”学校的地方，但多数院系页面仍停留在“栏目堆叠”：通知与新闻混在一起，最重要的三条信息被埋在第三屏。本选题从信息架构入手，先做卡片分类与任务路径，再决定视觉，目标是让四类典型访客都能在三次点击内找到答案。

02设计思路

页面按“身份”而非“部门”组织：顶部保留四个高频入口（教务、实训、展厅、招生），主体用“一主三副”的新闻版式，避免轮播图吃掉全部注意力。

  • 首屏只做一件事：让访客知道这是哪个系、能提供什么。
  • 通知公告用“日期块 + 标题”的紧凑列表，一屏可看五条。
  • 专业介绍用三张等高卡片，标签写清技能点而非课程名。
  • 配色克制：以纸白为底，朱红仅用于强调与分隔。

03“五心”主题体现

红心：栏目里保留“服务地方产业”的校企合作板块，把专业与张家港的产业现场连起来。仁心：文案不用行政腔，“企业工程师走进课堂”这类具体叙述替代口号。恒心：栏目结构改了四稿，删掉两个自认为好看但无人点击的模块。匠心：字号、行高、间距建立统一标尺，全站只用四级字号。创心：用原生 JS 做站内即时筛选，不引入任何框架。

04技术实现

栅格以 CSS Grid 为主，配合 clamp() 做流式字号；移动端在 860px、560px 两个断点重排。

CSS Grid 主栅格 clamp() 流式排版 语义化 header/nav/main 输入即筛选（原生 JS） SVG 线性图标 无外部依赖

05可拓展方向

  • 拆分出“师资队伍”“实训基地”等独立栏目页，形成完整站点。
  • 把新闻区接入后台管理，实现图文发布与审核（可对接 N—01 模板）。
  • 增加无障碍优化：跳转链接、焦点样式、对比度校验。
