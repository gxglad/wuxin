01选题背景

学校每年产生大量图文素材，却缺少一个“能一口气看完”的入口。招生季家长翻遍十几个公众号仍拼不出学校的样子；新生入学第一周也常找不到自己的位置。本选题以“一所学长的十二个月”为线索，用连续滚动的叙事替代分散的图文堆叠，让观看者在两三分钟内建立对校园的整体印象。

02设计思路

整体采用“深墨底 + 宣纸白 + 朱砂红”的江南书房配色，避免常见的高饱和科技蓝，与学校所在地域气质呼应。叙事节奏按“总—分—点”展开：主视觉给情绪，四季给时间跨度，“一日六时刻”给可交互的细节落点，最后以一句主张收束。

  • 主视觉用三层山形剪影叠出纵深，滚动时以不同速率位移，形成视差。
  • 四季用四组低饱和渐变作为“色卡”，让时间可被看见而不必依赖照片。
  • 交互只保留三处：时间切换、指针倾斜、填充悬停——少而明确。

03“五心”主题体现

红心：结尾落在“把学校讲清楚”这一朴素职责上，指向服务地方的形象传播。仁心：文案避免宣传腔，写具体的花瓣、蝉鸣、走廊灯，保留温度。恒心：四季段落逐字打磨，一处文案改七版。匠心：动效统一使用同一条缓动曲线，时长控制在 300—1000ms。创心：用纯 CSS + 原生 JS 实现视差与微交互，不依赖第三方动画库。

04技术实现

全站零依赖，单个 HTML 文件即可运行，便于答辩现场离线演示。

CSS 自定义属性控制色卡 IntersectionObserver 滚动入场 transform / opacity 合成层动画 pointermove 计算倾斜角度 prefers-reduced-motion 降级 SVG 剪影 + feTurbulence 颗粒

05可拓展方向

  • 接入真实校园摄影，把四季色卡替换为图片序列帧。
  • 增加“专业群”分支页面，每个专业一段独立叙事。
  • 导出 15 秒静帧动图，作为招生推文的配图版本。
