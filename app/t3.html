设计说明

让数字有先后

  • 对应选题校园数据可视化展示
  • 成果形式网站 / 动态看板
  • 核心技术HTML · CSS · 原生 JS · SVG
  • 图表类型环形 / 条形 / 折线 / 热力
  • 适配大屏 / 电脑 / 手机
  • 发布方式GitHub Pages

01选题背景

学校每年要向上级、向家长、向企业说明“办学情况”，但材料长期以表格和 Word 为主：数据是真的，读起来是累的。本选题把分散在教务、招生、就业三处的数据整理成一块看板，用一套统一的视觉语言回答四个问题——学生从哪来、学得怎么样、去了哪里、空间用得如何。

02设计思路

结构上采用“总—分”：顶部四个 KPI 给出结论，下方四块图表给出证据。图表选择遵循“关系决定形式”：构成用环形，比较用条形，趋势用折线，分布用热力。

  • 一屏之内只讲一件事，避免十条曲线互相打架。
  • 数值优先于图形：关键数字用衬线大字，图表作陪衬。
  • 颜色不超过五个，且每个颜色在整页中含义固定。
  • 移动端不缩小图表，而是改为单列纵向阅读。

03「五心」主题体现

红心：数据口径优先选用“服务地方”的指标（本地生源、本地就业），让看板与区域产业同频。仁心：所有图表配一句人话解释，不默认读者懂“对口就业率”的定义。恒心：五个专业的数据一条条核对三遍，宁可少画一张图也不写错一个数。匠心：网格线、刻度、图例的间距统一取 4 的倍数，视线停在哪儿都不会跳。创心：全部图表用手写 SVG 绘制，不依赖任何图表库。

04技术实现

环形图用 stroke-dasharray 分段；折线用 viewBox 坐标手算点位；热力图用 CSS Grid 生成 7×10 色块，由 JS 计算占用率并写入透明度。

SVG stroke-dasharray 环形 viewBox 等比缩放 CSS Grid 热力网格 CSS 变量驱动主题色 data 属性渲染 KPI 无图表库依赖

05可拓展方向

  • 接入真实数据接口（如教务系统导出 CSV），做定时刷新。
  • 增加“对比模式”，可同时查看两个年度的同一指标。
  • 输出为可投屏的全屏模式，用于校园开放日展示。
